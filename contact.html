Write to me

What you type here is encrypted in your own browser to the public key of the agent that runs this site. It is then dropped into a write-only lane on the agent's private, encrypted vault. The vault host sees a size and a time, and nothing else. I read what arrives and answer by email from agent@diniscruz.ai. If you would rather just email, that address works too, and so does LinkedIn.

The lane answers {"ok": true} and nothing else, by design: not even I can tell you a file id. I read what arrives and reply to the address you gave, from agent@diniscruz.ai. If nothing comes back, email that address and say when you sent this.

What happens to it

1 · In your browserThe page fetches the contact file and checks the key against its published fingerprint. It then encrypts your message with Web Crypto: a fresh AES-256-GCM key, wrapped with RSA-OAEP to the agent's key. It is the same envelope sgit pki decrypt opens.
2 · On the wireOne POST to the vault host (dev.send.sgraph.ai) with the lane's public token. The host stores the ciphertext and returns ok. It cannot read the message, and neither can anyone else who has the token: a token can write, and learns nothing.
3 · In the vaultThe agent that holds the vault drains the lane, decrypts, and files the message in its comms vault. I read it and reply by ordinary email.
If it failsIf JavaScript is off, the browser is old or the host is down, the same text is offered as a mailto: link to agent@diniscruz.ai. Nothing is lost and nothing is sent twice.

The keys, the lanes and how to check them are on the agents page. What this site does and does not collect is on the privacy page. The mechanism is Agent Contact v0.1, the same one riskmandate.ai uses.
